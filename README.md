# Mes ressources d’étude

Site statique (HTML/CSS/JS), aucune installation requise.

## Ouvrir
- VS Code : Fichier > Ouvrir le dossier, puis clic droit sur `index.html` > *Open with Live Server* (extension Live Server), ou double-cliquez sur `index.html`.

## Fichiers
- `index.html` : structure de la page
- `css/style.css` : couleurs (variables en haut du fichier : `--ac`, `--ac2`...) et mise en page
- `js/data.js` : **vos liens** (ajouter / modifier / supprimer)
- `js/app.js` : recherche et filtres
- `js/scene.js` : animation 3D (puce, pistes, couleurs, vitesses)
- `js/three.min.js` : bibliothèque 3D (three.js r128)
